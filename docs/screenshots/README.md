# Capturas

Capturas de la v1.0.0 tomadas en un emulador API 37 (Medium Phone, Android 16/37)
con el flujo de onboarding local, un gasto de ejemplo (`Coffee`, $12.50) y tasas
reales de dolarapi.

| Archivo | Pantalla |
|---|---|
| `01-onboarding-bienvenida.png` | Bienvenida del onboarding |
| `02-onboarding-modo.png` | Elección local vs remoto |
| `03-onboarding-setup-local.png` | Setup rápido local |
| `04-inicio-vacio.png` | Inicio sin movimientos (estado vacío) |
| `05-formulario-gasto.png` | Formulario de gasto en USD |
| `06-inicio-con-datos.png` | Inicio con totales, presupuesto y movimientos |
| `07-gastos.png` | Listado de gastos |
| `08-ajustes.png` | Ajustes: modo y preferencias |
| `08b-ajustes-apariencia.png` | Ajustes: apariencia, catálogos y Acerca de |
| `09-tasas.png` | Tasas BCV/paralelo con histórico |

Para regenerarlas: instala el APK debug en un emulador, limpia los datos de la
app y repite el flujo (onboarding local → gasto → Inicio → Gastos → Ajustes →
Tasas). Las capturas no llevan datos personales.
